# 💰 পরিবারের হিসাব (Family Hisab) — অ্যাপ প্ল্যান

> লক্ষ্য: একটা Android APK যেখানে **প্রত্যেক সদস্যের আলাদা হিসাব**, **পুরো পরিবারের যৌথ হিসাব**, আর সব মিলিয়ে একটা **রঙিন, প্রিমিয়াম ড্যাশবোর্ড** থাকবে। বাজার খরচ এন্ট্রি হবে ৩–৫ সেকেন্ডে।

## ১. পরিবারের সদস্য ও ভূমিকা

| সদস্য | সম্পর্ক | ভূমিকা (Role) | থিম রং |
|---|---|---|---|
| **Asif** | নিজে | 👑 লিডার / Admin — সব দেখতে ও এডিট করতে পারবে | নীল–বেগুনি `#6C5CE7` |
| **Irin** | স্ত্রী | সদস্য — নিজের হিসাব + পরিবারের এন্ট্রি দিতে পারবে | গোলাপি `#E84393` |
| **Ibad** | ছেলে | সদস্য (চাইলে শুধু দেখা/সীমিত) | সবুজ `#00B894` |
| **Moslem Mia** | আব্বু | সদস্য | কমলা `#E17055` |

- প্রত্যেকের নিজস্ব রং ও ছবি → ড্যাশবোর্ডে একনজরে চেনা যাবে।

## ২. হিসাবের মূল ধারণা (সবচেয়ে গুরুত্বপূর্ণ)

প্রতিটা এন্ট্রিতে দুইটা প্রশ্নের উত্তর থাকবে:

1. **কে টাকা দিল?** (`paidBy`) → Asif / Irin / আব্বু …
2. **কার জন্য খরচ?** (`spentFor`) → 🏠 **পরিবার** অথবা নির্দিষ্ট একজন (যেমন Ibad-এর স্কুল ফি)

এই দুইটা দিয়েই তিন ধরনের হিসাব বের হবে:

| হিসাব | কীভাবে আসে |
|---|---|
| 👤 **ব্যক্তিগত হিসাব** | `spentFor = ওই ব্যক্তি` — তার জন্য কত খরচ হল; আর `paidBy = ওই ব্যক্তি` — সে নিজে কত দিল |
| 🏠 **পারিবারিক হিসাব** | `spentFor = পরিবার` — বাজার, বিদ্যুৎ, গ্যাস, ভাড়া, ইন্টারনেট ইত্যাদি |
| 📊 **পুরো পরিবারের হিসাব** | সব এন্ট্রি একসাথে — মোট আয়, মোট খরচ, সঞ্চয় |

> উদাহরণ: আব্বু বাজার করলেন ১২০০ টাকা → `paidBy = আব্বু`, `spentFor = পরিবার`।
> Asif Ibad-এর জন্য জুতা কিনল ১৫০০ → `paidBy = Asif`, `spentFor = Ibad`।

## ৩. ফিচার তালিকা

### ✅ ভার্সন ১ (MVP — আগে এগুলো)
- **ড্যাশবোর্ড**: এই মাসের মোট আয়/খরচ/বাকি, সদস্যভিত্তিক কার্ড, ক্যাটাগরি চার্ট
- **⚡ Quick Add (বাজার খরচ সহজ এন্ট্রি)**
  - নিচে বড় `+` বাটন → বটম শিট খুলবে
  - বড় নাম্বার প্যাড (বাংলা/ইংরেজি সংখ্যা)
  - ক্যাটাগরি আইকন চিপ: 🛒 বাজার, 🐟 মাছ-মাংস, 🥬 সবজি, 🍚 চাল-ডাল, 💡 বিল, 🚌 যাতায়াত, 💊 ওষুধ, 📚 পড়াশোনা, 👕 কাপড় …
  - কে দিল / কার জন্য — সদস্যের ছবিতে এক ট্যাপ (ডিফল্ট: আমি / পরিবার)
  - "আগেরটার মত" — সাম্প্রতিক এন্ট্রি এক ট্যাপে আবার দেওয়া
  - সেভ = ১ ট্যাপ
- **🛒 বাজার লিস্ট মোড** (আইটেম ধরে): চাল ৫ কেজি ৳৪০০, আলু ২ কেজি ৳৮০… → মোট নিজে হিসাব হবে; আগের দামের সাথে তুলনা
- **আয় এন্ট্রি**: বেতন, ব্যবসা, অন্যান্য — কার আয়
- **লেনদেন তালিকা**: তারিখ/সদস্য/ক্যাটাগরি দিয়ে ফিল্টার ও সার্চ, এডিট/ডিলিট
- **সদস্যের প্রোফাইল পেজ**: ওই মানুষের মাসিক খরচ, নিজের দেওয়া টাকা, ক্যাটাগরি ভাগ
- **মাসিক রিপোর্ট**: মাস বদলে দেখা, আগের মাসের সাথে তুলনা
- **🔒 লক**: PIN / ফিঙ্গারপ্রিন্ট
- **ব্যাকআপ/রিস্টোর**: ফোনে ফাইল + Google Drive-এ এক্সপোর্ট
- **বাংলা UI** (ইংরেজি অপশন সহ), ৳ চিহ্ন

### 🚀 ভার্সন ২
- **বাজেট**: ক্যাটাগরি/সদস্য অনুযায়ী মাসিক সীমা, ৮০% হলে নোটিফিকেশন

- **PDF / Excel রিপোর্ট** — শেয়ার করা যাবে WhatsApp-এ
- **সঞ্চয় লক্ষ্য** (যেমন "ঈদের জন্য ২০,০০০")

## ৫. ড্যাশবোর্ড ডিজাইন (রঙিন + প্রিমিয়াম)

```
┌─────────────────────────────────────┐
│  আসসালামু আলাইকুম, Asif 👑   [নভেম্বর ▾]│
│ ╔═════════════════════════════════╗ │
│ ║  গ্রেডিয়েন্ট হিরো কার্ড (বেগুনি→নীল)  ║ │

│ ║  আয় ৳৫০,০০০ · বাকি ৳২১,৫৫০       ║ │
│ ║  ▓▓▓▓▓▓▓░░░ বাজেটের ৫৭%          ║ │
│ ╚═════════════════════════════════╝ │
│  আজ ৳১,২০০   |  এই সপ্তাহ ৳৬,৮০০     │
│                                     │
│  👥 সদস্যরা (আড়াআড়ি স্ক্রল কার্ড)       │
│  [🟣Asif ৳৯k][🩷Irin ৳৬k][🟢Ibad ৳৪k] │
│  [🟠আব্বু ৳৩k][🔵আম্মু ৳২k][🏠পরিবার ৳১৪k]│
│                                     │
│  🍩 ক্যাটাগরি ডোনাট চার্ট             │
│  📈 গত ৬ মাসের বার চার্ট              │
│  🕒 সাম্প্রতিক এন্ট্রি (৫টা)            │
│                          ( ➕ )      │
└─────────────────────────────────────┘
```

**ডিজাইন নিয়ম**
- Material 3 + কাস্টম থিম, **ডার্ক ও লাইট দুই মোড**
- গ্রেডিয়েন্ট হিরো কার্ড, গোলাকার কোণা (২৪dp), হালকা শ্যাডো / গ্লাস ইফেক্ট
- প্রতিটা সদস্যের নিজের রং → কার্ড, চার্ট, অ্যাভাটার সবখানে একই রং
- সংখ্যা এনিমেশন করে গুনে উঠবে (count-up), চার্ট স্মুথ এনিমেশন
- ফন্ট: **Hind Siliguri** (বাংলা) + **Poppins** (ইংরেজি/সংখ্যা)
- খরচ = লাল-কমলা টোন, আয় = সবুজ টোন

## ৬. টেকনিক্যাল প্ল্যান

| বিষয় | সিদ্ধান্ত |
|---|---|
| ভাষা | Kotlin |
| UI | **Jetpack Compose** + Material 3 (মডার্ন এনিমেশনের জন্য সবচেয়ে ভালো) |
| ডাটাবেস | **Room (SQLite)** — অফলাইন, ইন্টারনেট লাগবে না |
| আর্কিটেকচার | MVVM: Screen → ViewModel → Repository → Room |
| চার্ট | Vico (Compose চার্ট লাইব্রেরি) অথবা নিজে Canvas দিয়ে |
| সেটিংস | DataStore |
| লক | AndroidX Biometric |
| ব্যাকআপ | JSON এক্সপোর্ট/ইমপোর্ট (SAF) — পরে Firebase |
| টাকা সংরক্ষণ | `Long` পয়সায় (৳১২.৫০ = ১২৫০) — দশমিক ভুল এড়াতে |
| minSdk | 26 (Android 8+) |
| প্রজেক্ট | এই রিপোতে নতুন ফোল্ডার `family-hisab/` — আলাদা APK (`com.faiza.hisab`) |

### ডাটাবেস টেবিল

```
Member        (id, name, relation, role[ADMIN/MEMBER/VIEWER], color, photoUri, active)
Category      (id, nameBn, nameEn, icon, color, type[EXPENSE/INCOME], isBazar)
Transaction   (id, type[EXPENSE/INCOME/TRANSFER], amountPaisa, categoryId,
               paidByMemberId, spentForMemberId(NULL = পরিবার),
               date, note, receiptUri, createdAt, updatedAt)
BazarItem     (id, transactionId, itemName, qty, unit, pricePaisa)
Budget        (id, month, categoryId?, memberId?, limitPaisa)        ← v2
Debt          (id, memberId, otherPerson, amountPaisa, direction, settled) ← v2
```

### হিসাবের সূত্র (ইউনিট টেস্ট সহ লিখব)
- ব্যক্তিগত খরচ(X) = Σ খরচ যেখানে `spentFor = X`
- X নিজে দিয়েছে = Σ খরচ যেখানে `paidBy = X`
- পরিবারের খরচ = Σ খরচ যেখানে `spentFor = NULL`
- মোট খরচ = সব খরচের যোগফল; বাকি = মোট আয় − মোট খরচ
